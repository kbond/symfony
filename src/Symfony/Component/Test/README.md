# Symfony Test Component

## Sub-Components

- Browser (`symfony/test-browser`): migration of [`zenstruck/browser`](https://github.com/zenstruck/browser)
- Console (`symfony/test-console`): migration of [`zenstruck/console-test`](https://github.com/zenstruck/console-test)
- Foundry (`symfony/foundry`): migration of [`zenstruck/foundry`](https://github.com/zenstruck/foundry)
- Mailer (`symfony/test-mailer`): migration of [`zenstruck/mailer-test`](https://github.com/zenstruck/mailer-test)
- Messenger (`symfony/test-messenger`): migration of [`zenstruck/messenger-test`](https://github.com/zenstruck/messenger-test)
- Assert (`symfony/test-assert`): migration of [`zenstruck/assert`](https://github.com/zenstruck/assert):
  - Test-framework agnostic assertion system
  - Dependency of the above components
  - _Pest-like_ expectation system
- Panther (`symfony/panther`): migration of [`symfony/panther`](https://github.com/symfony/panther)
- DependencyInjection (`symfony/test-dependency-injection`): migration of [`matthiasnoback/symfony-dependency-injection-test`](https://github.com/SymfonyTest/SymfonyDependencyInjectionTest)
  - _With the permission/blessing of the current maintainers_
